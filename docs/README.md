# Output documentation

These pages describe the geographic output files generated by the scripts in this repository ([see the main README](../README.md) for how to run them).

The outputs below are organised by file type. The generated files cover a broad range of area types, from countries down to statistical Output Areas ([see table](Area-types-covered.md)).

**JSON format**
- [Area metadata files](Area-metadata-files.md)
- [Postcode lookup files](Postcode-lookup-files.md)
- [GeoJSON tiles](GeoJSON-tiles.md) (XYZ tiles for point-in-polygon lookups)

**CSV format**
- [Area lists](Area-lists.md) (by area type/year)
- [Master lookup](Master-lookup.md) (basic metadata for all areas)

**PBF format**
- [Vector tiles](Vector-tiles.md) (for web maps)

**Deployment**
- [Deploying to S3](Deploying-to-S3.md) (upload commands and headers for the gzipped outputs)
