# Master lookup

The master lookup file can be found in this repo at the following URL:

[https://github.com/ONSdigital/geo-scripts/blob/main/input/lookups/lookup.csv](https://github.com/ONSdigital/geo-scripts/blob/main/input/lookups/lookup.csv)

## About this file

This large CSV file contains metadata for all of the geographic areas that have individual [area metadata files](Area-metadata-files.md). It does not include area boundaries (polygons) or derived metadata like all parent and child areas, which can be found in the individual metadata files.

This file is not used directly in any web applications, but is used as a source to generate internal area lookups and metadata files within services such as [Explore Local Statistics](https://www.ons.gov.uk/explore-local-statistics/), and is useful in validating the other outputs generated by the scripts in this repo.

Column descriptions:

| Column | Description |
| ------ | ----------- |
| areacd | GSS code |
| areanm | Official name |
| areanmw | Welsh name (only for areas in Wales) |
| hclnm | Commons Library name (only for MSOAs) |
| hclnmw | Commons Library Welsh name (only for MSOAs in Wales) |
| parentcd | GSS code of immediate parent area |
| successorcd | GSS code of the area that replaced this one (only for terminated areas) |
| start | First year the area was valid (only for areas that are new since the earliest version) |
| end | Last year the area was valid (only for terminated areas) |
| areakm2 | Area in square kilometres |
| centroid | Centroid (_pole of inaccessibility_ calculated with [this script](https://github.com/mapbox/polylabel)) |
| bounds | Bounding box of area polygon |
