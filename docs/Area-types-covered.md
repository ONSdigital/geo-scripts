# Area types covered

The [outputs generated](README.md) by the scripts in this repo cover the following geography groupings:

| Area type | Short code | Type codes | Coverage |
| --------- | ---------- | -------------- | -------- |
| United Kingdom† | uk | K02 | UK-wide |
| Great Britain† | gb | K03 | GB |
| England and Wales† | ew | K04 | England and Wales |
| Countries | ctry | E92, N92, S92, W92 | UK-wide |
| Regions | rgn | E12 | England only |
| Combined authorities | cauth | E47 | England only |
| Counties* | cty | E10 | England only |
| Upper-tier/unitary authorities* | utla | E06, E08, E09, E10, N09, S12, W06 | UK-wide |
| Lower-tier/unitary authorities* | ltla | E06, E07, E08, E09, N09, S12, W06 | UK-wide |
| Westminster parliamentary constituencies | wpc | E14, N05, N06, S14, W07 | UK-wide |
| Senedd electoral regions | sener | W10 | Wales only |
| Senedd constituencies | senc | W09 | Wales only |
| Electoral wards | wd | E05, W05 | England and Wales |
| Parishes/communities | par | E04, W04 | England and Wales |
| Build-up areas | bua | E63, K08, W45 | England and Wales |
| Travel to work areas | ttwa | E30, K01, W22 | England and Wales |
| Middle-layer super output areas | msoa | E02, W02 | England and Wales |
| Lower-layer super output areas | lsoa | E01, W01 | England and Wales |
| Output Areas | oa | E00, W00 | England and Wales |

_†The United Kingdom, Great Britain and England and Wales are each a single area, made by merging their countries. Great Britain and England and Wales aren't part of the parent/child hierarchy of other areas._

_*Note that the cty, utla and ltla groupings have overlapping definitions, repeating some of the same type codes._
